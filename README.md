# Nithin R — Personal Portfolio

A premium personal developer portfolio built with vanilla HTML5, CSS3, and JavaScript.

## Tech Stack

- **HTML5** — Semantic, accessible markup
- **CSS3** — Custom properties, Grid, Flexbox, animations
- **Vanilla JavaScript** — No frameworks or dependencies

## Getting Started

Open `index.html` in any modern browser. No build system required.

## Features

- Terminal boot sequence with particle identity reveal
- Canvas-based particle background
- Custom cursor with smooth interpolation
- Animated hero code editor
- 3D tilt project cards
- Certificate lightbox viewer
- Contact form with validation
- Fully responsive (mobile-first)
- Accessible (keyboard nav, ARIA, reduced motion)
- SEO optimized
